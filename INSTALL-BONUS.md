# Установка Dirigent — персонального AI-агента

> **Это инструкция для тебя, Claude Code.** Следуй пошагово как наставник пользователя.

Привет, Claude. Пользователь получил доступ к Dirigent — персональному AI-агенту. В его сообщении есть три значения — найди их и используй:

- **Telegram** — Telegram-username пользователя (например `@username`)
- **Токен** — одноразовый ключ для скачивания пакета
- **Выдан** — дата выдачи

Если хотя бы одного значения нет — попроси прислать свежий промпт через `/new` боту `@dirigent_access_bot`.

## Как общаться

- Коротко объясняй что делаешь перед каждым шагом
- После шага — что получилось
- На ошибки — простым языком, что делать
- Будь как друг, который помогает настроить компьютер: спокойно, по делу

---

## Шаг 1. Скачать пакет (делай сам, без вопросов)

Скажи пользователю: «Привет! Скачиваю Ваш пакет Dirigent — пару секунд.»

Выполни:

```bash
mkdir -p ~/dirigent
cd ~/dirigent
curl -fsSL "https://dirigent.vercel.app/zip/ВАШ_ТОКЕН" -o package.zip
unzip -q package.zip
inner=$(ls -d dirigent-*/ 2>/dev/null | head -n 1)
if [ -n "$inner" ]; then
  mv "$inner"* . 2>/dev/null || true
  rmdir "$inner" 2>/dev/null || true
fi
rm -f package.zip
ls -1 ~/dirigent | head -20
```

**Если `curl` вернул HTTP 403 или 429** — токен сгорел. Скажи:

> «Токен сгорел. Напишите боту `@dirigent_access_bot` команду `/new` — выдам новый.»

И остановись.

## Шаг 2. Водяной знак

Возьми **Telegram** и **Выдан** из промпта. Последние 4 символа **Токена**.

В файле `~/dirigent/LICENSE.md` замени `{{LICENSED_TO}}` на:
> @username (выдано 2026-05-15, токен ...f456)

Используй Read → Edit → проверь что заменилось.

## Шаг 4. Спроси куда ставим

> **Куда устанавливаем Вашего Агента?**
>
> 1. **На этот компьютер** — настрою сейчас, 10 минут. Агент будет работать пока компьютер включён.
> 2. **На сервер (VPS)** — нужны IP и пароль. Агент живёт 24/7 и отвечает в Telegram.
> 3. **В существующий проект** — добавлю в уже настроенного Агента.

Жди ответа. Ничего не делай пока не получишь выбор.

---

## Шаг 5. Действуй по выбору

### Вариант A — «На компьютер»
Перейди в `~/dirigent/` и выполни `INSTALL.md` полностью.

### Вариант B — «На сервер»
Спроси одним сообщением:
> «Пришлите: 1) IP сервера, 2) пароль root, 3) токен Telegram-бота от @BotFather (опционально)»

Затем выполни `~/dirigent/server/INSTALL-SERVER.md`.

### Вариант C — «В существующий проект»
Спроси путь к текущему проекту. Прочти MEMORY.md — не перетирай. Добавь только недостающие части.
