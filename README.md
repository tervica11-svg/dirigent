# Dirigent — персональный AI-агент

**Dirigent** (нем. «дирижёр») — ваш личный нейросотрудник на базе Claude Code.

Не чат-бот. Не помощник в браузере. Агент, который живёт на вашем сервере, знает ваши проекты, помнит каждый разговор и становится умнее каждый день.

## Что умеет

- 💬 Общается в Telegram 24/7
- 🧠 Помнит ваши проекты, привычки, договорённости
- 🎤 Понимает голосовые сообщения
- 📸 Читает фото и документы
- 💻 Пишет код, делает сайты, автоматизирует задачи
- 📋 Составляет планы, отчёты, контент

## Структура

```
dirigent/
├── workspace/          ← душа агента (правьте смело)
│   ├── SOUL.md         ← характер и стиль
│   ├── MEMORY.md       ← долгосрочная память
│   ├── GOALS.md        ← ваши цели
│   ├── CLAUDE.md       ← правила работы
│   └── memory/         ← дневники по дням
├── bot/                ← Telegram-бот (движок)
├── server/             ← установка на VPS
└── INSTALL.md          ← инструкция установки
```

## Установка

Вы получили персональный промпт от `@dirigent_access_bot`.

1. Откройте Claude Code
2. Вставьте промпт и нажмите Enter
3. Claude Code настроит всё сам (~15 минут)
